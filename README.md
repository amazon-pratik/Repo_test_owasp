# AWS Guru LLM Benchmarks

This repository contains comprehensive LLM benchmark test cases for multiple programming languages, designed to train and evaluate AI models on secure coding practices and vulnerability detection.

## Overview

The AWS Guru LLM Benchmarks project provides a systematic collection of code examples covering:

- **Security Vulnerabilities**: CWE-categorized examples of common security issues
- **Best Practices**: Secure coding patterns and recommended approaches
- **Multi-Language Support**: 11 programming languages with consistent patterns

## Supported Languages

- **C++** - Systems programming security patterns
- **C#** - .NET security best practices
- **Go** - Modern concurrent programming security
- **Java** - Enterprise application security
- **JavaScript** - Web application security
- **Kotlin** - Android and JVM security
- **PHP** - Web backend security
- **Python** - General-purpose security patterns
- **Ruby** - Web framework security
- **Scala** - Functional programming security
- **TypeScript** - Type-safe web development

## Structure

Each language directory contains:
- CWE-categorized vulnerability examples
- Best practices demonstrations
- Both vulnerable and secure code patterns
- Comprehensive documentation

## Usage

These benchmarks are designed for:

1. **LLM Training**: Teaching AI models to identify and fix security issues
2. **Model Evaluation**: Benchmarking AI performance on security tasks
3. **Developer Education**: Learning secure coding practices
4. **Tool Validation**: Testing static analysis and security tools
